# Freedom Arena Graphics Pipeline

## Integrated foundation
The pipeline now feeds the existing Canvas2D world renderer. It does not change world coordinates, collision rules, pathfinding, combat, or save data.

## Asset factory
- Five authored biome palettes: temperate, arid, frozen, volcanic, coastal.
- Seven material classes: ground, water, rock, wall, sand, snow, lava.
- Deterministic seeded generation and stable asset IDs.
- Tile sizes: 64, 128 and 256 px.
- Periodic edge-cell values for repeatable tile patterns.
- Material-specific detail passes and palette accents.

## Runtime integration
`web/src/main.tsx` maps the existing world biome index to the graphics palette and draws generated materials through the texture cache. The cache is bounded to 512 entries and evicts the oldest inserted texture when full. Gameplay remains owned by `world.ts`.

## Graphics Studio
The React studio supports:
- Biome, material, seed and resolution selection.
- Single-tile and 3×3 mosaic preview.
- PNG and WebP export, with adjustable WebP quality.
- JSON metadata export.
- A local asset catalog (up to 60 descriptors) persisted in browser local storage.

The local catalog is device-local; it is not synchronized to Supabase or GitHub. Export JSON and image files for transfer between machines.

## Validation
Unit tests cover stable IDs, deterministic random sequences, all biome/material palette combinations, repeat-edge cell values and the 64 px world-grid contract. GitHub Actions runs `npm run test` and `npm run build` for changes under `web/**`.

## Known limits
- The world renderer is still Canvas2D and top-down/pixel-stylized; this is not yet a production isometric 3D renderer.
- Character and building authoring, skeleton animation, VFX authoring and atlas packing are not implemented yet.
- The material generator is procedural art, not a physically based material pipeline. It does not yet generate normal, roughness, metallic or height maps.
- The current biome assignment follows the four biome bands generated by `world.ts`; the coastal palette is available in the studio but not yet assigned by world generation.
